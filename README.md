# ML Algorithms From Scratch

This repository contains implementations of various Machine Learning algorithms from scratch to understand their core concepts, mathematics, and working.

## Algorithms

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Naive Bayes
- And more...

## Purpose

The main goal of this repository is to understand how Machine Learning algorithms work internally by implementing their core logic without directly relying on ready-made model implementations.

## Tools & Libraries

- Python
- NumPy
- Scikit-learn
